# Lifeboard v0.5 — 03.11.2026

## Что изменено

1. **Новая цель:** прокрутка к форме через `nextTick()` и `scrollIntoView` с поддержкой reduced motion. Повторное нажатие снова прокручивает к уже открытой форме.
2. **Theme / locale:** компактный popover ~224 px в ширину, уменьшены высоты/паддинги; исправлена позиция на небольших экранах.
3. **Сад целей:** заменена старая визуальная пирамида на вертикальный «росток» с кактусом, четырьмя горизонтом целей, активными связями и отдельной sticky-панелью описания (mobile: последовательно). Нажатие `+` открывает форму с нужным горизонтом, а родитель выбирается только при логичной иерархии.
4. **ИИ-Консалт:** кнопка в хедере, PrimeVue Dialog с `<InDevelop />`. Никакого реального AI/API ещё нет.
5. **Декомпозиция:** связанные цели теперь выбираются через `PrimeVue Select` с `filter`. Дополнительно переведены селекты категории и горизонта.
6. **Фокус месяца:** явно выбранные до 3 целей, редактирование через `FocusManager`, отображение в сайдбаре/аналитике; store сохраняет `focusGoalIds` и восстанавливает их из v0.4 backup. Повторные и отсутствующие ID нормализуются.
7. **CSS:** без глобального параллакса; лёгкая глубина лишь внутри «сада»; анимации поддерживают `prefers-reduced-motion`.
8. **README:** handoff документ с 20 разделами и будущим REST API-контрактом (пока не реализован).

## Безопасность / совместимость

- Все данные по-прежнему в `localStorage`.
- Никакой полноценной серверной авторизации, OAuth или OpenAI вызовов.
- JSON-формат `lifeboard:state:v1` обратно совместим с v0.4.
- Frontend остаётся на `8080`, Budgee на `80` не изменяется.
