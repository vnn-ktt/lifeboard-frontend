# Lifeboard v0.6 — Notes, winding garden and responsive layout

## Изменения

- `/notes` — новый полноценный раздел: карточки (заголовок, текст, фото), группы, привязка к целям, фильтры по группе и цели, поиск по содержимому, pin/unpin, CRUD.
- Изображения JPEG/PNG/WebP проверяются (≤5 МБ) и перед сохранением сжимаются в JPEG. Рекомендуется хранить только небольшие изображения: данные всё ещё в localStorage.
- Notes и NoteGroups добавлены как **необязательные поля LifeState v1**; существующий `lifeboard:state:v1` и формат JSON-резервных копий сохранены без смены версии.
- `deleteGoal` отвязывает от цели заметки и группы, но не удаляет их. Удаление группы оставляет заметки без группы.
- Локализация раздела заметок на RU/EN/DE, пункт в десктопном меню и нижней мобильной навигации.
- Кнопка ИИ-Консалта стала компактнее, диалог больше не блокирует скролл страницы; `html { scrollbar-gutter: stable; }` устраняет скачок ширины при overlay.
- Hero: текст, кактус со статистикой и progress ring лежат в адаптивной CSS-сетке без перекрывающих absolute-position элементов.
- Сад целей: извилистый SVG-путь с мягкой анимацией, небольшие смещения карточек на desktop; упорядоченная вертикальная траектория на mobile.
- Дополнительные unit-тесты: CRUD заметок, импорт v0.5, связи, сохранность после удаления групп/целей.

## Ограничения

- Реальная авторизация и синхронизация отсутствуют: всё в localStorage браузера.
- Фото хранится в base64 внутри JSON; не подходит для больших коллекций. Дальнейший шаг: object storage через backend.
- Нет совместной работы, drag-and-drop и Markdown-редактора. Заметки — обычный текст, ссылки не выполняются и не превращаются в HTML.
- При сбросе данных через профиль удаляются также заметки. Экспорт JSON сначала.
- AI-Консалт пока только заглушка.
