# Lifeboard v0.7 — компактность, wizard и рефакторинг

Дата: 3 ноября 2026 г. Статус: frontend-only, Docker Compose, без backend.

## UI/UX

1. Сад целей с 30–50 записями: не более 4 целей на уровень в превью; локальное раскрытие и прокрутка; выбранная цель остаётся видимой при сворачивании.
2. Удалена избыточная надпись «Твоя извилистая тропа роста».
3. Удалён крупный рекламный баннер заметок; фильтры групп/целей, сортировка и действия сосредоточены в шапке доски.
4. Компактные кнопки и плотная сетка карточек по всем актуальным экранам Lifeboard.
5. Мобильное окно заметки уменьшено, поля и кнопки адаптивны.
6. «ИИ-Консалт» перешёл на собственный reusable overlay (без изменения ширины body и PrimeVue scrollbar compensation).
7. Новая цель: трёхшаговый wizard (название и смысл → горизонт/сфера → измеримое действие и родитель), короткие переходы.
8. Альтернатива: быстрая форма одной страницей. Режим выбирается в профиле и хранится в обычной cookie для настройки интерфейса.

## Данные и исправления

1. Один `createId()` для целей, заметок и профиля: поддерживает `crypto.randomUUID`, `getRandomValues`, а при их недоступности — локальные id без криптографических гарантий. Исправлено падение при HTTP.
2. Бэкап включает все поля состояния (цели, привычки, отметки, рефлексию, категории, группы и карточки заметок, встроенные фотографии). Сохраняется обратная совместимость с ранними JSON.
3. 10 примерных целей и 8 заметок / 3 группы — только для новой пустой установки. Для уже использующих браузер доступна **явная** операция «Профиль → Добавить примеры», она не заменяет существующие записи.
4. Подсчёт прогресса большой карты переведён на итерацию реальных отметок в `utils/goalProgress.ts` вместо создания календаря на пять лет для каждой карточки.

## Рефакторинг

- `components/goals/GoalCreator.vue` — UI ввода цели;
- `composables/useGoalDraft.ts` — wizard/validation;
- `utils/gardenPreview.ts` — ограничение длинных списков;
- `utils/goalProgress.ts` — эффективная статистика;
- `composables/useNotesBoard.ts` — логика заметок и фильтрации вне представления;
- `composables/useLifeBackup.ts` — импорт/экспорт;
- `data/seed.ts` — демонстрационные данные;
- `shared/utils/createId.ts` — единый генератор идентификаторов;
- `shared/stores/useUiPreferencesStore.ts` — Pinia + cookie для режима ввода;
- `shared/components/Overlay/AppOverlayDialog.vue` — универсальное всплывающее окно;
- `lifeboard-ui.css` — объединение двух каскадов стилей, удаление устаревших правил;
- удалены старые неиспользуемые mock-auth-компоненты и дублирующее поле формы.

Legacy-финансы Budgee сознательно сохранены, так как маршруты и UI используются. Удаление *всего* устаревшего кода без запуска регрессии не считается безопасным рефакторингом.

## Контроль качества

- Проверка TS/Vue синтаксиса, CSS и импортов: пройдена.
- 14 автономных smoke-assertions на реальные методы состояния: пройдены.
- Функция `gardenPreview` с 50 целями проверена отдельно.
- Добавлены тесты для ID, превью сада, прогресса по горизонтам, дополнены тесты store.
- **Полный Vite build и браузерное e2e не были выполнены в текущей среде** из-за отсутствующих `node_modules` и недоступности реестра пакетов. Обязательная проверка на VPS: `docker compose build --no-cache lifeboard`, затем QA по `docs/QA-v0.7.md`.

Важно: cookie в этом выпуске хранит только предпочтение интерфейса. Она **не является** серверной сессией и не защищает данные.
